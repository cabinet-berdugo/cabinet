# Cabinet Berdugo — application interne

Page de l'application (tâches, planning, congés) publiée avec GitHub Pages.

- Les données restent dans le Google Sheet « App cabinet » ; la page appelle le serveur Google Apps Script du cabinet.
- Aucune donnée n'est stockée dans ce dépôt. L'accès demande un compte (e-mail + mot de passe) créé par l'administrateur.
- `sw.js` permet l'ouverture rapide et les notifications sur téléphone ; `manifest.webmanifest` permet d'installer l'application sur l'écran d'accueil.

Fichiers générés automatiquement : ne pas modifier à la main.
